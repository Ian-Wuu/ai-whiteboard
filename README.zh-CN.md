<h1 align="center">AI Whiteboard</h1>

<p align="center">与 AI 一起说、画、操作。</p>
<p align="center"><a href="README.md">English</a> · 中文</p>

一个本地运行的 AI 白板原型。你与千问实时语音对话，AI 把解释放到白板；你修改文字、移动元素或调整参数，AI 接收操作后的实际状态。

![设计讨论场景：阅读空间参考图与可编辑的空间分析标注](docs/assets/scene-design.jpg)

## 能做什么

- **边说边画**：千问实时语音、转写、打断，以及受限制的白板工具调用。
- **共同编辑**：文字、形状、箭头、自由绘制和图片；支持移动、缩放和撤销。
- **操作而不只是观看**：利率滑块、方案开关、时间线、加法计算器四种受控模板，支持放大与本地恢复。
- **AI 放图片**：语音请求搜图，AI 可将验证后的参考图片放进白板，保留来源链接与域名。
- **精确反馈**：提交后的数值、文字和位置进入 AI 上下文，不把鼠标每一帧移动发送给模型。
- **多板与对话记录**：浏览和编辑历史板，AI 默认工作在当前 LIVE 板；白板、最终转写及互动状态保存到本机浏览器。

## 三个一起思考的场景

### 推敲一个决定

利率从 3% 变成 6%，到底意味着什么？把比较放在真正可拖动的利率滑块旁边：相同本金、相同期限，不同月供。

![利率决策场景：3% 与 6% 对比，以及实际可操作的利率滑块](docs/assets/scene-finance.jpg)

### 把概念讲清楚

从房间温控器理解反馈循环：观察、比较、调整，再观察。可编辑流程图搭配时间线，所选阶段可以进入 AI 上下文。

![概念学习场景：反馈流程图、温差计算与互动时间线](docs/assets/scene-learning.jpg)

### 讨论一个设计

首页展示阅读空间的设计讨论：一张参考图、几条关于光线与形体的观察，以及一个继续探索的问题。回到历史白板，继续整理思路。

![设计场景的历史回看，包含回到当前按钮与空白对话面板](docs/assets/scene-history.jpg)

这些是预先整理后在真实应用中截取的示例板，不是生成式 UI 效果图，也不证明 AI 已自动完成整套内容。空间参考图由 imagegen 生成后手动插入；文字和流程图是可编辑标注。滑块与时间线真实可操作，但周围的图表和对比条不会随之自动更新。没有伪造对话转写。详见[素材来源](docs/GITHUB.md)。

## 快速开始

需要 Node.js 22 与 pnpm。下载或克隆本仓库后，在项目目录打开终端。

### 先试白板，不需要 API Key

```bash
pnpm install
pnpm dev:web
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。此模式可编辑白板和操作组件，语音与搜图不可用，也不会产生模型调用费用。

### 开启 AI 语音与搜图

1. 在阿里云百炼准备北京地域的 API Key、业务空间 ID，以及可用的实时语音与图片搜索模型。
2. 将 [.env.example](.env.example) 复制为项目根目录的 `.env`，填写密钥和业务空间 ID。已有 `.env` 时不要覆盖。
3. 如果刚才启动了纯白板，先在终端按 `Ctrl+C` 停止，再运行：

```bash
pnpm dev
```

打开同一地址，点击「开始对话」并允许麦克风权限。建议戴耳机。点击「结束对话」断开语音；终端按 `Ctrl+C` 关闭开发服务。

详细配置、故障排查与数据说明：[配置指南 / Configuration](docs/CONFIGURATION.md)。

### Mac 双击启动与关闭

首次安装依赖并配置 `.env` 后：

- 双击 `启动 AI Blackboard.command`：启动服务并打开网页。
- 双击 `关闭 AI Blackboard.command`：停止由启动器开启的服务。
- 只关闭网页不会停止本地服务。文件保留旧名称，产品界面已改为白板。
- Windows 使用上面的终端命令，不使用 `.command` 文件。

## 试着这样交互

开始语音后，可以说：

- “用三步流程解释一下复利，把关键点放在白板上。”
- “放一个利率滑块。”将滑块调到 6%，再问：“现在是多少？月供怎样变化？”
- “找一张自行车的参考图片，放在白板右边。”
- 手动添加文字或移动元素后说：“读一下我刚写的内容，它现在在什么位置？”
- “换一块白板。”然后返回历史板查看和继续编辑。

模型是否调用工具、搜到什么图片，取决于模型与网络情况。AI 当前可以读取结构化文字、位置和互动值，**尚不能识别自由笔迹或图片内容**。手动编辑通常先更新上下文，不会每次都主动插话。

## 当前边界

这是本地原型，不是可直接公开部署的完整 V1：

- 没有账号、邀请、云同步、跨设备恢复或可靠的多标签页编辑锁。请只在一个标签页编辑。
- 数据保存在当前浏览器、当前地址的 IndexedDB 中；清除站点数据会丢失，`localhost` 与 `127.0.0.1` 也不是同一存储空间。
- 没有应用内费用硬限制。语音和搜图由百炼收费，请在供应商控制台设置提醒，使用后结束对话。
- 搜索图片仍使用外链，没有存入自有云存储，可能加载失败或失效；来源标注不等于取得版权。
- AI 不能改写、移动或删除用户拥有的元素；一次性授权修改流程尚未实现。
- 尚未完成云端部署、自动重连及完整的 Windows/macOS 跨浏览器验收。后端无身份认证，不应通过公网或隧道暴露。

本项目不持久化原始音频；启用语音后，音频、白板上下文与转写会发送给模型服务商。更多说明见 [SECURITY.md](SECURITY.md)。

## 开发

React + TypeScript + Vite · Excalidraw 0.18.1 · Zustand + Zod · IndexedDB · Fastify + WebSocket · 阿里云千问

```bash
pnpm test     # 逻辑测试，不调用付费模型
pnpm build    # 类型检查与前端构建
```

`pnpm start` 只启动后端，不是完整产品的生产部署命令。

- `src/`：界面、唯一 BoardStore、互动组件与浏览器音频。
- `server/`：千问中继、图片搜索与工具校验。
- `scripts/`：本机启动与关闭。
- `docs/`：双语配置、GitHub 介绍素材和截图。
